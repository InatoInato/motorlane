name: backend-task
description: Implement or fix Python FastAPI backend features with tests and minimal complexity.
---

1. Inspect existing code and architecture.
2. Define the smallest implementation that meets the ticket.
3. Preserve existing patterns; avoid unnecessary layers.
4. Implement the feature and regression tests.
5. Run relevant tests and fix failures.
6. Review the diff for bugs and security issues.
7. Report changes, test results, and remaining risks.

Never deploy or change unrelated code.
